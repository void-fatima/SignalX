Owners: Roham for release/source ZIP and hosting, Fatima for demo/video/pitch,
Setayesh for technical AI documentation and measured reports. No release has
been created by the file-skeleton stage.

Before packaging, gather:

- Product URL with working registration/login/logout and two-user isolation.
- README and current architecture/API documentation.
- Business plan and pitch deck with verified claims and no invented metrics.
- 3–5 minute video link showing the actual online end-to-end flow.
- Setayesh's model/prompt/score versions, evaluation and cost report, examples
  and limitations. Clearly distinguish Mock from real runs.
- Source code ZIP/tag with locked dependencies and instructions for clean setup.

Exclude .env, secrets, local DB, virtualenv, node_modules and build caches from
the source package. Verify all links and the required URL availability period
against competition rules. No automatic publishing or release tagging is done
by these templates.
