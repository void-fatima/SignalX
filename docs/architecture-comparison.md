# مقایسهٔ اسکلت فعلی و برنامهٔ پنج‌روزه

مبنای مقایسه: کد موجود، PDF جدید و سند هفت‌روزهٔ اولیه.
PDF طرح/برنامه است؛ موارد تعریف‌شده در آن به‌معنای پیاده‌سازی یا موفقیت آزمایش نیستند.
نسخهٔ PDF در docs/sources نگهداری شده؛ متن استخراجی ممکن است ترتیب کلمات و اعداد
فارسی را به‌هم بریزد و جایگزین PDF نیست.

| موضوع | اسکلت فعلی | سند جدید | تصمیم |
| --- | --- | --- | --- |
| معماری | Modular Monolith، worker مستقل، PostgreSQL queue | همان انتخاب | حفظ اسکلت فعلی |
| ساختار فایل | routes/core/db/models/schemas/services/agents + migration/tests/contracts | درخت خلاصه‌تر + auth | حفظ تفکیک فعلی؛ auth واقعی توسط رهام افزوده می‌شود |
| Auth | ندارد؛ محلی | P0، register/login/logout/me | الزام جدید ثبت شد؛ هنوز ساخته نشده |
| جداسازی کاربران | یک محیط محلی مشترک | user ownership الزامی | migration/queryهای scoped و تست دو کاربر قبل از آنلاین شدن |
| تقسیم تیم | شماره‌های 1/2/3 | رهام/ستایش/فاطیما؛ تمام UI با فاطیما | نام‌ها و مالکیت جدید اعمال شد |
| زمان‌بندی | هفت روز؛ deploy دیرتر | پنج روز؛ deploy روز 2؛ freeze روز 4 | برنامهٔ جدید مرجع جاری؛ تاریخ مسابقه از آن استنتاج نمی‌شود |
| Scoring | وزن‌ها/مرزها مشخص، half-up | همان وزن‌ها/مرزها، round مبهم | half-up و score_v1 حفظ شد؛ وزن‌ها به نام فیلد متصل شدند |
| Screening | اشاره‌های ثابت به دوره بک‌اند و substring برای it | وابسته به محصول/context | کلمات از پروفایل محصول استخراج و مرز واژه رعایت شد |
| Qualification | validation داخل pipeline | structured output + guards | به ماژول مستقل منتقل شد؛ NaN/مقادیر جهش‌داده‌شده هم دوباره validate می‌شوند |
| Provider | Mock داخل pipeline ساخته می‌شد | Mock/Real adapter | factory مستقل؛ real.py اکنون فقط slot صریح fail-closed است، نه اتصال واقعی |
| Cost | صفر Mock ثبت می‌شد | real usage/versioned rates/unknown | منطق Decimal، نرخ با واحد صریح و null/N/A آماده شد؛ اتصال paid/budget هنوز باقی است |
| Evaluation | هنوز ندارد | dev/test مستقل و confusion matrix | ماژول خالص و CLI اضافه شد؛ داده و گزارش عملکرد واقعی هنوز نداریم |
| Reply/Feedback | خارج از bootstrap | لازم تا روز 4 | مرز مالکیت ثبت شد؛ endpoint/UI صوری ساخته نشده |

اسکلت فعلی در جزئیات فنی و قابلیت اجرا مناسب‌تر است؛ سند جدید در مالکیت، Auth و
اولویت تحویل مرجع بهتری است. ترکیب انتخاب‌شده، معماری جاری docs/architecture.md است.
تغییرهای این مرحله API عمومی، schema ذخیره‌سازی و UI را عوض نمی‌کنند.

دو محدودیت مهم حفظ می‌شوند: Mock همان demo است و Agent واقعی محسوب نمی‌شود؛
cost/evaluation utility آماده به‌معنای اندازه‌گیری واقعی یا enforce شدن budget نیست.
